# Современный Go: идиомы, обязательные на нашей версии

Проект собирается на Go 1.26.5. Всё перечисленное здесь доступно в тулчейне —
проверено `go doc`, а не взято из статей. В новом коде — только эти формы;
старый переписывается, когда его и так трогаешь, отдельными правками не гоняется.

## Ошибки

- `errors.AsType[T](err)` вместо `errors.As(err, &target)` — не нужна временная
  переменная, тип виден в вызове.
- `errors.Is(err, target)` вместо `err == target` — сравнение не переживает обёртку.
- `errors.Join(err1, err2)` — когда ошибок несколько и нужны все.

## Конкурентность

- `wg.Go(fn)` вместо тройки `wg.Add(1)` + `go func()` + `defer wg.Done()`:
  забыть `Done` больше нечем.
- `errgroup` — когда воркеру есть чем упасть и падение должно останавливать остальных.
  `WaitGroup` берётся, только если воркеры ошибок не возвращают.
- Переменная цикла с Go 1.22 своя на каждой итерации: `item := item` и передача
  через параметр `go func(x int){}(i)` — лишние.
- `sync.OnceFunc` / `sync.OnceValue` вместо `sync.Once` с обёрткой.

## Тесты

- `t.Context()` вместо `context.Background()`: контекст сам отменяется в конце теста
  и ловит утечку горутин.
- `testing/synctest` — для всего, что завязано на время или на согласование горутин.
  Даёт детерминированные фейковые часы вместо `time.Sleep`.
- `b.Loop()` вместо `for i := 0; i < b.N; i++` в бенчмарках.

## Язык и стандартная библиотека

- `for i := range n` вместо `for i := 0; i < n; i++`.
- `any` вместо `interface{}`.
- `min`, `max`, `clear` — встроенные, свои реализации не писать.
- `slices` и `maps` вместо ручных циклов поиска, сортировки и копирования.
- `strings.Cut`, `CutPrefix`, `CutSuffix` вместо `Index` со срезами.
- `cmp.Or(a, b, "default")` вместо лесенки проверок на пустоту.
- `math/rand/v2` вместо `math/rand`.
- `new(значение)` вместо `x := значение; &x`.

## JSON

- `omitzero` вместо `omitempty` для `time.Time`, структур, срезов и карт:
  `omitempty` их не опускает, потому что нулевыми в смысле `omitempty` они не бывают.
  Для указателей и скаляров `omitempty` по-прежнему верен — там он и работает.
